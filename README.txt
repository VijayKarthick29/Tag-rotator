# ⟡ Tag Rotator

**Automated Discord Guild Badge Rotation Tool**

A Python-based Discord utility designed to automate guild badge rotation, simplify configuration, and provide convenient startup management.

## ✨ Features

- Automated guild badge rotation
- Configurable settings
- Lightweight Python implementation
- Startup automation support
- Windows batch launchers
- Dependency management

## 📁 Project Structure

```text
Tag-rotator/
├── config.json
├── guild_badge_rotator.py
├── install_24_7_startup.bat
├── README.md
├── requirements.txt
├── setup_startup.py
└── start_guild_rotator.bat
```

## ⚙️ Requirements

- Python 3.x
- Required Python packages
- A properly configured Discord environment

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/VijayKarthick29/Tag-rotator.git
```

2. Enter the project directory:

```bash
cd Tag-rotator
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Configure `config.json` according to the project's settings.

5. Start the application using the provided launcher.

## 🖥️ Startup

The project includes Windows startup utilities:

- `setup_startup.py`
- `install_24_7_startup.bat`
- `start_guild_rotator.bat`
